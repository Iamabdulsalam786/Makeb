# MAKCOMMs - Enterprise Business Consulting & Technology Solutions

> **Connecting Businesses** • Your Business Requirements. Our Tailored Solutions.

MAKCOMMs is a business consulting, technology, and professional services company delivering tailored ERP solutions, IT infrastructure, custom AI & technology, corporate training, professional talent, and BPO outsourcing across domestic and international markets.

## Key Features
- **Executive Architecture:** 8 Enterprise Solution Pillars (ERP, Web & SaaS, Mobile Engineering, Cybersecurity, AI & Agents, Cloud & IT, Talent Augmentation, BPO Desks).
- **Interactive Tools:** Compact single-screen consultation inquiry form, live instant capability search, MakBot concierge assistant.
- **Responsive Navigation:** Desktop mega-menus and fully responsive mobile drawer sidebar with accordion submenus.
- **Adaptive Theming:** Seamless dark and light enterprise visual modes.

## Quick Start
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```
